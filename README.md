# ニャンコ大運動会 Online v0.5 — 3競技アクション画像移植

Render用のオンライン版です。6桁の部屋コード・2人＋CPU2匹・5区間レース→格闘→綱引き→総合優勝の進行を維持します。

## 今回
- 1人用PLiCy版のキャラクターの待機・走り・攻撃・ジャンプ・被弾・ダウン・綱引き画像を正式に同梱し、描画で使用。
- 既存の四角い格闘ステージ画像を同梱。
- キャラクター向きの無入力時の反転バグを修正。

## 未移植 / 重要
これは完全移植ではありません。1人用の全物理演算・全障害物ロジック・綱引きトーナメント・リズムレーンの挙動・全演出を同一化してはいません。通信サーバーは別実装のため、ゲームバランスは異なります。完全移植にはサーバーと描画の再構成が必要です。

## Render更新
GitHubの同じリポジトリに全ファイルを同じディレクトリ構成で反映し、Renderで最新版が Live になったら、ブラウザを再読み込みしてください。
