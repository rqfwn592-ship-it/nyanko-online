# ニャンコ大運動会・原作ベースオンライン 統合検証版（3回目）

## 起動
pip install -r requirements.txt
python server.py
ブラウザ2台から http://localhost:10000/online.html を開きます。公開時は Render のURL末尾に `/online.html` を付けてください。

## 実装・変更
- 元のレース・格闘・綱引きエンジンを `/static/sports/*.txt` に保持
- 2人用ロビーと原作ゲームホスト（1P）、リモート入力（2P）、状態スナップショット
- 競技完了通知の重複防止、順位配列の検証、競技番号の整合性チェック
- 1→2→3競技→総合発表への遷移と、総合得点のネタバレ防止
- 2Pの通信停止時の入力解除

## 注意
ホスト側に判定処理が集中するP2P類似方式です。完全なサーバー権威型ではなく、回線遅延やホスト切断に弱い点が残ります。
実機での端末2台による長時間の通しプレイ、タップタイミング、特に綱引きの決勝と個別勝敗は引き続き検証が必要です。
現時点で原作と完全同等のネット対戦が保証された完成品とは断言できません。
