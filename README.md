# ニャンコ大運動会 ONLINE v2.4 — 同期待機・結果発表修正版

原作を使ったオンライン版 v2.3 からの更新です。

- 各競技前に1P・2Pの「準備OK！」待機画面を表示。両者が押して初めて開始。
- 2Pの原作説明カバーを閉じ、ホストのスナップショットを表示。
- レース／格闘／綱引きの各終了時に両方の端末で1位〜4位を順に発表。
- その時点の合計ポイントと順位を表示し、各競技の優勝者の画像を表示。
- 1Pが進行操作すると、次の競技の準備画面が両方に表示される。
- サーバーが競技番号と進行段階を厳密に管理して重複レースを防止。
- 最終競技後は総合順位を表示。

## Renderで更新する際
ZIPを解凍し、既存のGitHubリポジトリに中身を配置してコミットしてください。
RenderがLiveになったら `/online.html` を開いてください。
