# 熱血！ニャンコ大運動会 原作ONLINE v2.3 修正パッケージ

## 今回の修正
- 2Pの通信更新時に位置を補間し、レース・格闘のカクつきを軽減（完全解消は実機未確認）
- 親画面にBGM・効果音・アップロード音源の再生エンジンを追加。タイトル画面をタップすると音声を許可
- 2Pで原作内操作パッドを非表示にしてオンラインパッドだけ表示（重複防止）
- サーバーの `event.next` に含まれる競技番号を採用して、競技遷移を同期
- 終了通知が複数来た場合の二重処理防止

## Renderへの更新
ZIPを解凍して、GitHubの `server.py`、`static/online.html`、`static/sports/` 等を入れ替え、RenderがLiveになったら `/online.html` を開いてください。
