# 熱血！ニャンコ大運動会 ONLINE v0.2 通信対戦強化版

2人が別端末から同じURLを開き、6桁コードで入室して対戦する専用サイト版です。スマホ2台＋CPU2匹で、クロスカントリー5区間→格闘60秒→綱引き→総合結果まで進行できます。

## Renderへの更新方法

このZIPを解凍して、中身の `server.py`、`static/index.html`、`static/assets/` 等を、既存GitHubリポジトリの同じパスに**上書き**してコミットしてください。特に **`server.py` と `static/index.html` の両方**が更新されている必要があります。GitHub連携のAuto DeployならRenderが再デプロイします。手動の場合はRenderの Manual Deploy → Deploy latest commitを実行してください。既存のURLと同じ部屋コード方式で遊べます。

Build: `pip install -r requirements.txt`
Start: `python server.py`

## 現段階の範囲と制限

これは **オンライン対戦の強化試作 v0.2** です。1人用Ver.1.7の完全移植版ではありません。
- レース: 共通障害物、被弾・ジャンプ、共通スケボー、最終区間スケボー無し、5区間タイム合計を実装。ただし1人用の奥行き移動・武器投げや全背景演出は未移植です。
- 格闘: 2人の移動、パンチ、4種の必殺技を識別した攻撃処理、HP、KO減点、場外、魚/爆弾の取得と爆弾投げ、暫定得点を実装。1人用の高度なアニメーション・投げ技・物理挙動はまだ簡易版です。
- 綱引き: 連打とリズム入力、CPU、結果同期は現段階のオンライン試作のまま。既存のリズムレーンと完全なトーナメントは未移植です。
- 各イベントの順位はサーバー側で集計。競技ごとの結果では総合点は伏せます。

## ローカル起動

Python 3.10+ で `pip install -r requirements.txt`、`python server.py` して `http://localhost:8080` を開きます。

オンラインの公開はRenderに更新してください。接続中の既存セッションは更新デプロイで切れます。
